# Dados

Esta pasta contém os dados utilizados pelo projeto.

A modelagem utiliza a base analítica da camada Gold,
produzida no Tech Challenge da Fase 2.

Arquivo necessário:
- data/gold/base_analitica_alfabetizacao.parquet

Os arquivos de dados não são versionados no Git devido
ao seu tamanho.

Para reproduzir o projeto, é necessário gerar a camada
Gold com o pipeline da Fase 2 e disponibilizar o arquivo
no caminho indicado acima.

Links simbólicos locais não são suficientes para garantir
a reprodução em outro computador.
